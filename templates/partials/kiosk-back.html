{# In-page back control — for a page whose own sub-views need one. Include inside a {% with %} that names the view to return to: {% with back_label='About LSPU', back_action='hub' %} {% include 'partials/kiosk-back.html' %} {% endwith %} ## This is no longer the way out of the kiosk It used to be: every destination included this partial with `back_href=route('kiosk')` to render a full-width "◀ Kiosk menu" bar, plus an inline handler that preferred history.back() so the menu came back from the bfcache with its ticker intact. All of that is gone, along with the `back_href` branch that rendered it. The carousel in welcome.html is the kiosk's navigation now — it is on screen at all times, below the content, and moving it changes the section directly. There is nothing to go "back" to: the menu never went away, and a bar labelled "Kiosk menu" sitting under a permanently-visible kiosk menu was the last remnant of the open/close model this replaced. What remains is the case §8 of the spec explicitly protects — a control that belongs to the *content* rather than to kiosk navigation. About LSPU is the only user: its detail panes are client-rendered views of a single URL, so they have no address to link back to and no way out except a button its own JS listens for (`about-lspu-kiosk.js`, on `[data-back]`).
